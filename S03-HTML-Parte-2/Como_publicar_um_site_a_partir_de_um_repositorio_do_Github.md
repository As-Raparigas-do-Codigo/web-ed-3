# Como publicar um site a partir de um repositório do Github

Se estás a ler este artigo, espero que já tenhas o teu projecto no Github, porque lhe vamos dar vida. 👩‍🔬

Não te preocupes se ainda não está na versão final que desejas, podes sempre actualizar o site de acordo com as novas alterações ao código.

### Github pages - o que é?

O [GitHub Pages](https://pages.github.com/) é um serviço de hospedagem para sites estáticos que obtém os ficheiros de HTML, CSS e JavaScript diretamente de um repositório no GitHub. 

Adicionalmente executa os ficheiros por meio de um processo de construção, chamado "build" que publica o site.

### Como faço para ter o meu site publicado aqui?

1. Primeiro tens de ter um conta no [Github](https://github.com/)
2. Tens de ter um repositório criado e com o teu código (testa o código no teu computador para garantir que está tudo OK)
3. No teu repositório, acede ao separador "Settings" e depois clica em "Pages"

![githubpages1](https://user-images.githubusercontent.com/39055313/135725380-daf77fad-08ee-4013-945b-47469510fa61.jpeg)

4. No source, muda para o branch "master" ou "main"

![githubpages2](https://user-images.githubusercontent.com/39055313/135725385-a6ad65d2-1c42-4ae1-a37a-6c949e0637a7.jpeg)

5. E está publicado!

![githubpages3](https://user-images.githubusercontent.com/39055313/135725399-69fe8bcd-41eb-46c3-926e-0b4336361dae.jpeg)

6. Podes adicionar o link na página do teu repositório, assim quem vir o teu código consegue logo ver o resultado final:

![githubpages4](https://user-images.githubusercontent.com/39055313/135725420-1c57ea30-211f-4fce-9691-8d1e6881c54e.jpeg)

Partilha o teu site no Discord para vermos :)
