## Planeamento

| Sessão | Módulo | Tópicos |
| ------------- |-------------|-------------|
|<b>S01</b><br>6 Nov | -- | Sessão de abertura. Introdução ao curso.<br>Formato e modo de funcionamento.<br> Instalação das ferramentas necessárias (e.g., editor de texto, browser).| 
|<b>S02</b><br>13 Nov | <b>HTML</b> | Introdução ao HTML.<br> Tags e estrutura base de uma página web.<br>Tags elementares para apresentação de texto (e.g., cabeçalhos, parágrafos).<br>Atributos de tags. Exemplos mais comuns.<br>Imagens. Links. Bookmarks. Organização de ficheiros. Listas. Tabelas.
|<b>S03</b><br>20 Nov | <b>HTML</b> | Formulários. HTML semântico (e.g., `header`, `nav`, `section`).<br> Atributos `id` e `class`. Elementos `div` e `span`.<br> Caracteres especiais. Multimédia.<br>Validação de documentos HTML.|   
|<b>S04</b><br>27 Nov | <b>CSS</b> |Introdução ao CSS. Sintaxe. Aplicação do CSS.<br> Heranças de formatação CSS. Tipos de folhas de estilo.<br>Selectores básicos (e.g., tag, class, id).<br>Tipografia. Cores. Posicionamento. Box Model. Fundos.<br>Pseudo-classes e pseudo-elementos.<br>Animações em CSS. Display. Unidades. Media Queries.|

|<b>S06</b><br>11 Dez | <b>JS</b> | Introdução ao JavaScript. Sintaxe. Output e comentários.<br>Instruções condicionais. Instruções iterativas.<br> Instruções `break` e `continue`. Funções. Eventos.|
|<b>S07</b><br>18 Dez | <b>JS</b> | Document Object Model (DOM).<br>Exercícios.|
