# 💻 Instalação de Software:
No decorrer dos workshops vais precisar de um editor de texto para escreveres o teu código (HTML, CSS, JS) e de um navegador (um browswer) que interprete esse código (onde vemos os resultados!). Nestes workshops iremos usar:

- [ ] Google Chrome
- [ ] Sublime Text


⚠️ **Nota:** Não é obrigatório usar o Google Chome ou o Sublime especificamente para acompanhar as aulas ou resolver os exercícios. É apenas mais fácil se todos os alunos utilizarem o mesmo browser e editor na resolução de bugs e apoio por parte dos mentores. Alguns aspetos podem variar entre editores e browsers, como por exemplo:

- Aceder ao menu de developer (código fonte da página, consola de javascript);
- Alguns resultados podem variar entre browsers (Chrome vs Safari);
- Comandos rápidos (abertura e fecho de tags, formatação de texto);
- Packages úteis (por exemplo, de formatação automática);

No entanto, se já tens outro browser (e.g., Firefox, Safari) ou editor de texto (e.g., VS Code, Notepad++) com que te sentes confortável, excelente! 😄


## Google Chrome
1. Acede ao [site oficial](https://www.google.com/chrome/);
2. Clica em "Transferir o Google Chrome";
3. Clica no ficheiro executável que foi descarregado;
4. Deves ter agora o Chrome instalado no computador.

- [x] Google Chrome

<br>

## Sublime Text
1. Acede ao [site oficial](https://www.sublimetext.com/);
2. Clica na opção de download que for mais indicada para o teu sistema operativo;
3. Clica no ficheiro executável que foi descarregado;
4. Escolhe o destino onde tencionas instalar o editor de código (o predefinido serve perfeitamente);
5. Clica "Next" e depois "Install";
6. Clica em "Finish" e deverás ter o "Sublime Text" instalado no teu computador.

- [x] Sublime Text

<br>

## Opcional: Package Control (para o Sublime Text)
1. No Sublime Text, procura o menu "Tools" e clica em "Install Package Control";
2. Agora, no menu "Tools", deves encontrar a "Command Pallete";
3. Procura por "Package Control: Install Package" e faz ENTER ou clica nele;

- [x] Package Control

Com a Package Control instalada, podes instalar quaisquer packages (ferramentas) que te ajudem a tornar desenvolvimento de código mais fácil (e divertido). Por exemplo, podes instalar o [HTMLBeautify](https://packagecontrol.io/packages/HTMLBeautify) para identar (formatar) o teu código HTML:

1. No menu "Tools", vai a "Command Pallete" e procura por "Package Control: Install Package";
2. Escreve "HTMLBeautify" e clica (ou ENTER);

- [x] HTMLBeautify (comando no MacOS: Command-Option-Shift-F)

# 🚀 Desafio Pós-Aula
## [CTF #1] Capture the Flag 🚩

Em tech, um CTF (Capture The Flag) está normalmente associado à área de cibersegurança e é um desafio que envolve precisamente a captura de uma "bandeira" (uma flag).

Pois bem, nós escondemos uma 🚩 no nosso website. Será que consegues encontrá-la com algo que aprendeste nesta sessão?

Acede a https://raparigas-do-codigo-ctf.herokuapp.com e faz o registo com o teu nome e email (usem os mesmos que usam no registo dos workshops).

Depois... it's game on! 😄 O objectivo é encontrar a bandeira o mais rapidamente possível! Acredita que consegues completar o desafio, e não compliques! 😊 

👉 Se completares o desafio, podes partilhar connosco se gostaste e que conseguiste terminar mas cuidado para não dar pistas ou spoilers às tuas colegas! Não estragues o jogo para ninguém!!! 😅

Diverte-te! 😊 E veremos quem se sagra campeã! 🏆 👏
